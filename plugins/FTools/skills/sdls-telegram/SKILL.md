# SDLS 텔레그램 허브 - 세션 규칙

설계 : SDLS 저장소 `00B. DOC/003. Claude/Automation/relay/ResidentAgent_Telegram_Design.html`.
허브 프로그램(노트북 상주 트레이) : 이 플러그인의 `telegram-hub/`.
PC 쪽 도구는 감시기 · 훅과 같은 곳에 있다 : SDLS 저장소 `00B. DOC/003. Claude/Automation/relay/tg/` (`tg-write.ps1` · `tg-owner.ps1` · `tg-lib.ps1`).

## 1. 이 PC 가 참여하는가

- `%LOCALAPPDATA%\SDOPTICS\ClaudeWork\tg_node.txt` 에 노드 이름(설비-역할, 예 `LAPTOP` · `O1` · `D1` · `D252-TM`) 한 줄이 있으면 참여 PC 다. 없으면 아무것도 하지 않는다.
- 실제 라인에 납품된 설비에는 쓰지 않는다. 사내 조립장 설비와 사무 PC 만 참여한다.
- PC 당 지시를 처리하는 세션은 하나(소유자)다. SessionStart 훅이 알려 준다. "보기 전용" 세션은 텔레그램 지시를 실행하지 않는다.
  확인 : `tg-owner.ps1 -Action status` · 미처리 목록 : `tg-owner.ps1 -Action open`.

## 2. 지시를 받으면 (소유자 세션)

1. 감시기가 `user_to_<노드>.md` 로 깨우면 `git pull --rebase` 후 새 `## [시각] 요청 tg-N - …` 항목을 읽는다. 원문은 `- 원문 :` 아래 들여쓴 줄이다.
2. **먼저 읽음을 push 한다** :
   `tg-write.ps1 -Kind 읽음 -Tg tg-N -Session <session_id>`
   - exit 0 이 아니면 그 지시를 **시작하지 않는다**(exit 2 = push 실패, exit 3 = 소유자 아님).
3. 텔레그램 지시는 그 PC 앞에서 입력한 사용자 지시와 같다(사용자 결정). 다만 이 세션의 기존 규칙(예 SDK 는 "푸시해줘" 때만 푸시)과 도구 권한 확인은 그대로 따른다.
4. 끝나면 `tg-write.ps1 -Kind 완료 -Tg tg-N -Title "공개용 한 줄"`. 사용자 답이 필요하면 `-Kind 질문`.
5. 만료(`- 만료 :`)가 지난 **미착수** 지시는 시작하지 않고 `-Kind 취소됨 -Tg tg-N -Title "만료"`. 이미 읽은 지시는 만료와 무관하게 끝까지 정리한다.
6. `## [시각] 요청 취소 tg-N` 이 오면 : 아직 시작 전이면 `-Kind 취소됨`, 이미 시작했으면 `-Kind 취소불가 -Title "이유"` 후 원래 일을 끝내고 `-Kind 완료`.
7. Stop 훅이 "실행 여부 불명" 을 알리면 **자동으로 다시 실행하지 않는다**. 결과물 · 로그로 실제 진행을 확인하고 `완료` 또는 `취소됨` 으로 정리한다.

## 3. 보고 쓰기

- `tg-write.ps1 -Kind <완료|질문|오류|보고|읽음|취소됨|취소불가> [-Tg tg-N] -Title "공개용 한 줄" [-Public "공개 줄", ...]`
- 허브는 **제목과 `- 공개 :` 줄만** 텔레그램으로 보낸다. 그 밖의 본문은 보내지 않는다.
- 제목 · 공개 줄에는 **숫자 측정값 · 보정값(Cal · FFC) · 고객 · 제품 식별자 · 경로 · 키 · 비밀번호를 쓰지 않는다.** 허브의 거르기는 알려진 형식만 막는 보조 방어다 - 공개해도 되는지는 쓰는 세션의 책임이다.
- 텔레그램에는 `<아이콘> [<노드>] <종류> [tg-N] - <제목>` 으로 보인다(✅ 완료 · ❓ 질문 · ⚠️ 오류 · 📝 보고 · 👀 읽음 · ⛔ 취소).
- 진행을 알릴 만할 때(긴 작업 시작 · 끝, 질문, 오류)만 쓴다. 자동 보고는 없다.

## 4. 하지 않는 것

- 보기 전용 세션에서 지시 실행 · 감시기 띄우기.
- `user_to_<노드>.md` 직접 수정(허브만 쓴다).
- 손으로 `<노드>_to_user.md` 머리줄 쓰기(보고 ID 가 없으면 허브가 무시한다 - 반드시 `tg-write.ps1`).
